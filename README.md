### Overview

The Council is an interactive web application that summons legendary personalities to answer your questions. Ask anything — from life dilemmas to philosophical queries — and watch as 4 legendary minds bicker, philosophize, and spectacularly disagree. Features a comic book aesthetic with dynamic background music that adapts to the emotional tone of your question, plus a "vibe level" slider to control how unhinged the personalities get.

---

### Usage

Simply open `index.html` in a web browser — no build process or dependencies required.

1. Type your question or opinion in the text area
2. Click "Randomize" to select 4 legendary personalities (or use the default selection)
3. Adjust the "Vibe Level" slider to control personality intensity (Sane → Quirky → Weird → Unhinged → Gay)
4. Click "Summon The Council" to get responses
5. Enjoy the dynamic background music that matches your question's emotional tone

---

### Tech Stack

- **Frontend**: Pure HTML, CSS, and JavaScript in a single file
- **Backend**: Cloudflare Workers API for AI-powered personality responses
- **Emotion Detection**: Hugging Face models for mood-based music selection
- **Audio**: Tone.js for dynamic, mood-responsive background music
- **Styling**: Custom CSS with comic book aesthetic (speech bubbles, starbursts, dot patterns)

---

### Features

- **32 Legendary Personalities**: From Socrates and Einstein to fictional characters like Sherlock Holmes and cultural icons like Salman Khan
- **Dynamic Music Engine**: 8 distinct musical moods (lounge, thriller, soap opera, circus, epic reveal, elevator music, cartoon chaos) that adapt to your question's emotion
- **Adjustable Vibe Level**: Control how unhinged the personalities' responses are
- **Comic Book UI**: Bold typography, speech bubbles, animated loading effects, and vibrant colors
- **Responsive Design**: Works on desktop and mobile devices
